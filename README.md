# 图片合成工具箱

浏览器本地运行的图片批量背景合成工具，无需安装、无需上传服务器，打开网址即用。

**在线使用：https://wuhengqwe.github.io/image-compose-toolbox/**

## 功能

- **批量背景合成**：同时上传多张产品图 × 多张背景图，自动排列组合，一次生成全部合成图
- **产品图默认居中**：位置固定不变，产品图与背景图均按 1:1 处理
- **按比例缩放产品图**：支持整体缩放 + 微调
- **保存到指定文件夹**：批量下载时可直接选择本地文件夹保存
- **全屏去背编辑器**：AI 智能去背（u2netp 模型，浏览器本地推理）、自动去背、画笔 / 橡皮涂抹、手动框选、钢笔勾选
- **多格式支持**：产品图支持 JPG / PNG / WebP 等常见格式

## 使用建议

- 推荐使用 Chrome / Edge 浏览器（「保存到指定文件夹」需要浏览器支持文件夹选择功能）
- AI 智能去背首次加载模型约 5–15 秒，之后秒开；模型文件（约 4.5MB）随页面一起加载
- 所有图片处理均在浏览器本地完成，不会上传到任何服务器，隐私安全

## 本地使用

下载本仓库后双击 `index.html` 即可离线使用（本地模式自动加载内置资源）。
